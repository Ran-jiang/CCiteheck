CCiteheck 法律引用核查

在 Word 里一键核查法规与司法案例引用:定位条文、比对权威原文、给出修订建议。按你的系统选择安装方式,约 3 分钟完成。

下载 manifest.xml
  1. 完全退出 Word(按 Cmd+Q,不只是关闭窗口)。
  2. 在 Finder 中按 Cmd+Shift+G,粘贴 ~/Library/Containers/com.microsoft.Word/Data/Documents/wef/ 并回车,把刚下载的 manifest.xml 复制进该文件夹。
    提示"找不到该文件夹"?

    该文件夹通常在 Word 首次打开后才创建:先正常打开一次 Word(再 Cmd+Q 退出),重试上面的路径。若还是没有,在打开的 Finder 窗口里新建一个名为 wef 的文件夹,再复制进去。

    App Store 版 Word 可能不支持旁加载;公司托管的 Mac 若提示"没有权限",请联系管理员或用个人电脑安装。

  3. 重新打开 Word,在 主页 → 加载项 中找到 CCiteheck 并点击启动。
熟悉终端?一键安装器更快

下载 install-ccitecheck.command,退出 Word 后双击运行。

首次运行如提示"无法验证开发者":右键该文件并选择"打开"。如提示"权限不足":打开"终端"App,输入 chmod +x (注意 x 后有一个空格),把该文件拖进终端窗口再按回车,之后双击即可运行。

下载 manifest.xml
  1. 打开 Word(2016 或更新版本 / Microsoft 365;不支持 WPS),进入 插入 → 获取加载项。

    找不到"获取加载项"?部分版本的入口是 主页 → 加载项 → 更多加载项(或"高级"),打开的是同一个窗口;注意不是"文件 → 选项 → 加载项"。

  2. 在弹出窗口顶部选择 我的加载项 选项卡,看该页最上方:上传我的加载项是"查看全部"旁边的小字链接,不是按钮(英文版叫 "Upload My Add-in";部分版本需先点"管理我的加载项"才能看到它)。
  3. 在文件选择框中选中刚下载的 manifest.xml,点 打开 并确认提示。CCiteheck 即出现在 主页 → 加载项 中,点击即可启动。

    选择框里只能选本地文件,不能直接粘贴网址;若下载被浏览器拦截,在浏览器地址栏打开 https://cciteheck-api.onrender.com/manifest.xml 后另存为 manifest.xml。

看不到"上传我的加载项"?按顺序排查

1. 它是文字链接,只在"我的加载项"选项卡顶部出现;不在"主页"选项卡里,也不是按钮。

2. 点 Word 右上角登录任意 Microsoft 账户(个人或工作/学校账户均可),未登录时该链接可能隐藏。

3. 把 Office 更新到最新:文件 → 帐户 → 更新选项 → 立即更新,装完重启 Word。

4. 公司/学校账户可能被管理员禁用旁加载,入口会被隐藏。可换个人账户登录,或把 https://cciteheck-api.onrender.com/manifest.xml 发给管理员集中部署。

5. 都没有解决?改用下面的一键安装器。

还是不行?下载 Windows 一键安装器

同时下载 install-ccitecheck.bat 和 install-ccitecheck.ps1 到同一个文件夹(.bat 依赖同目录下的 .ps1),完全退出 Word 后双击 .bat,允许管理员权限,窗口显示完成后打开 Word。

然后在 开始 → 加载项 → 高级 → 共享文件夹 中选中 CCitecheck,点 添加。安装器被公司策略拦截时,可改用手动方式:新建文件夹(如 C:\CCiteheck)放入 manifest.xml 并共享,在 Word 的 文件 → 选项 → 信任中心 → 信任中心设置 → 受信任的加载项目录 中添加该共享路径,勾选"在菜单中显示",重启 Word 后到"共享文件夹"中添加。

安装后在 Word 中打开任意文档,点击“核查全文”即可。核查时文档内容会上传至部署方服务器处理,请勿核查含敏感个人信息的文书。
